# chataxi 0.4.2 对话身份与交互修订

本次修改收敛模型分类、群聊艾特、用户身份、消息操作和朗读静音语义。

底部导航增加“我的”，保存用户名称、本地头像和自我介绍。头像沿用图库选择与拖动裁切组件。每次模型请求都加入用户名称与自我介绍；具体对话的非空自我介绍会替换通用介绍。模型页分类改为不带图标的“对话模型、朗读模型、语音输入”，设置页删除重复的最近 N 条入口，N 只在具体对话内配置。

群聊输入区改为单行 `@` 角色条。每轮只能选择一位角色，角色名最多显示五个字符，较长名称显示前四个字符与省略号；角色较多时只有该条局部横向滚动。选择结果写回对话，下一轮和重新进入时继续选中。空消息仍会写入明确的艾特继续消息后再调用该角色。

完成的角色回复新增独立重新生成按钮。首次压缩前，全部完成消息都可编辑或重新生成；生成共享摘要后，只有摘要边界之后且属于该对话最近 N 条的完成消息可操作。重新生成非末尾回复时先确认删除后续消息，再让原角色从该位置生成。

对话头像统一为圆形，消息气泡保留浅黄色主题并使用左右排列、小尖角和紧凑操作栏。段落空行在显示层收敛为普通换行，不改变持久化文本或提交给模型的上下文。首页卡片右侧进入对话区域使用主题亮黄色。

右上角喇叭控制本对话后续自动朗读，并保存静音状态。静音不会停止已经开始的音频；播放状态由 TTS 状态机独立驱动，播放期间图标为绿色，即使已经静音。静音与未静音分别使用关闭音量与正常音量图标，手工点击消息朗读仍可使用。

自动检查覆盖五项导航、无图标模型分类、用户资料与对话覆盖上下文、单角色艾特记忆、静音不触发停止、播放颜色状态、压缩前后操作范围以及重新生成入口。源码检查和 DOM 流程不等于真机视觉、供应商请求或音频设备验收。
