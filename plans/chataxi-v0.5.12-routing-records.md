# chataxi 0.5.12 自动选角诊断记录

自动选角的模型调用属于运行诊断，不属于对话语义。每轮预选都在 `messages` 集合中保存一条 `kind: "routing"` 记录，包含主持人和候选角色、服务与具体模型、模型原始文本、响应 ID、用量、解析或请求错误、最终选中角色、是否随机兜底及耗时。记录不保存 API Key、请求头或完整提示词。

`store.messages(conversationId)` 是产品运行时唯一的普通历史读取入口，会先排除 `kind: "routing"`，因此对话显示、搜索、上下文压缩、最近 N 条和模型请求都不会读到选角记录。开发诊断通过 `store.routingRecords(conversationId)` 单独读取，结果按发生时间排序；用户界面不展示这些内部记录。删除对话和按时间删除后续消息时，诊断记录跟随同一消息前缀和时间边界清理。

失败记录保留模型已经返回但未通过严格角色名校验的原始文本；网络、认证或服务错误只保存经过密钥清洗的错误信息。诊断写入发生在随机兜底之后、角色正式回复之前，从而同时记录真实使用的兜底角色。
