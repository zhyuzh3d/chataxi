# chataxi v0.4.16 消息编辑与增量压缩修订

消息编辑改为单一保存动作。编辑 Sheet 不再提供“重新生成”开关，也不因编辑旧消息删除后续记录。角色回复下方的重新生成按钮负责生成操作；目标回复后存在任何消息时，先通过危险操作确认 Sheet 明确删除用户与全部角色的后续消息，再由原角色重新生成。

每个概要记录以 `throughMessageId` 和对应时间标记实际覆盖边界。N 表示每次压缩后保留的最近完整消息下限：阈值未触发时，概要边界后的全部未压缩消息进入回复上下文；触发时，只把最近 N 条之前的未压缩前缀与上次概要合并。连续压缩只推进边界，不删除原始消息，并累计记录覆盖消息数。

单聊使用该角色压缩，群聊固定使用参与角色列表中的第一位角色。压缩模型同时收到所有参与角色及当前用户的名称与介绍作为说话者辨认资料；系统提示明确要求只压缩消息，不摘录或概括参考资料本身。

版本号为 0.4.16，版本代码为 31。源码继续通过局域网实时服务提供，不生成 0.4.16 ZIP。直接测试覆盖未压缩上下文完整保留、两轮概要合并、精确边界推进、最近 N 条操作窗口、群聊第一角色压缩和参与者参考资料隔离。
