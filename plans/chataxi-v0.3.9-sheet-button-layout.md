# chataxi 0.3.9 Sheet 与按钮布局修订

此前横排容器虽然声明了 `gap`，但不少区域使用 Flexbox。部分 Android WebView 不可靠地呈现 flex-gap，导致 Sheet 底部、标题栏、模型服务卡和聊天工具栏中的相邻按钮在手机上贴合。现在固定按钮组使用 CSS Grid；可换行或内容数量变化的按钮组使用明确的按钮外边距，不再依赖 flex-gap。

检查范围包括主 Sheet 与二级 Sheet 的取消/保存按钮、确认 Sheet、角色卡双按钮、模型服务卡操作、标题栏双按钮、聊天消息操作、图片与语音按钮、角色点名 Chip、快捷问题按钮、头像操作和头像裁切缩放控件。按钮内部的图标与文字也使用明确外边距。

弹层根节点、遮罩和 Sheet 同时声明视口左右边界及 100% 宽度，主 Sheet、二级选择 Sheet、菜单 Sheet 和确认 Sheet 共享同一条全宽规则；不再以 `inset` 作为唯一定位依据。

移动端底部 Tab 栏使用 `position: fixed` 固定到视口底部，应用外壳从首帧开始预留底栏与安全区高度。桌面宽屏媒体查询将其恢复为静态侧栏。验证脚本会持续检查全宽 Sheet、按钮组间距和固定底栏这些结构约束；本轮没有执行浏览器截图或真机视觉验收。
