# chataxi 0.4.5 朗读服务保存修订

## 问题

ElevenLabs 连接成功后，接口返回的模型目录可能与内置目录合并。旧逻辑把模型和音色列表同时当作“连接信息”参与签名；保存时又把表单中的 ID 列表还原为带能力信息的发现结果。模型目录权限受限并使用内置目录时，这两个等价状态的内部表示不同，因此被错误判断为用户修改了连接信息。

## 修复

- 连接签名只包含真正决定远端连接的模型家族、端点、协议、API Key 和自定义 Header。
- 模型与音色 ID 使用单独的目录签名，只负责判断能否保留发现到的能力元数据。
- 连接后仍保留模型与音色的完整对象；用户实际修改家族、地址、协议、密钥或 Header 时，仍必须重新连接。

## 验收

DOM 流程模拟 ElevenLabs 取得模型和音色、完成合成验证并立即保存，确认不会出现错误的“连接信息已改变”提示，并确认音色和启用模型写入服务记录。
