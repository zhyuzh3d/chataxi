# chataxi 0.4.4 凭据展示修订

## 目标

统一模型服务中已保存凭据的展示与复制。用户能够通过首尾字符确认当前配置，并在明确点击后复制完整值，同时避免完整凭据进入页面 HTML、属性、日志或错误信息。

## 实现

- LLM、TTS、ASR 共用同一个 API Key 展示组件，保留首尾字符并固定遮罩中段。
- 已保存 API Key 旁提供复制按钮；替换输入框保持密码类型且默认留空，防止掩码被误存成新密钥。
- 自定义 Header 不再把旧 JSON 回填到文本框。每个已有 Header 值都遮罩显示并可单独复制；留空保留旧配置，填写 JSON 整体替换，也可用开关明确清除。
- 完整值只在复制事件闭包和请求适配器内使用，不写入 `data-*`、标题、可访问标签或 HTML。
- 切换模型家族时隐藏旧家族的凭据展示，并继续执行原有的不跨家族继承规则。

## 验收

自动测试覆盖短值、长值、Bearer 值、自定义 Header、DOM 无明文、复制返回原值和留空保存不破坏旧凭据。发布包仍保持纯原生运行闭包。
