# chataxi 0.3.0 收敛重构记录

日期：2026-09-13  
范围：chataxi happ 源码、产品合同、自动测试和版本化归档；不含部署、手机安装和真机视觉验收。

## 交付结果

0.3.0 将主导航收敛为“对话、角色、模型、设置”。模型服务、朗读和语音输入从设置中独立出来，服务只保存模型家族和连接信息，角色保存具体 LLM/TTS 模型、生成参数、音色和支持时的音色提示词。官方家族自动给出协议与端点；llmserver 和自定义端点保留必要的手工配置。

页面删除内容区重复眉题、大标题和介绍，统一卡片密度、按钮间距、头像位置和四标签布局。所有新增、编辑、菜单和确认都使用自定义底部 Sheet。角色卡的编辑与开始对话按钮等宽；角色编辑支持图标头像、颜色、模型基础/进阶参数和朗读配置。

群聊角色点选移动到输入框内。用户可以只点名一个角色回答，也可以在空文本时发出明确的点名继续消息。每个角色请求包含全部参与角色设定、对话共享的压缩内容，以及从用户和所有角色消息中统一取得的最近 N 条完整消息。

新增对话级共享压缩记录、通用压缩参数和逐对话 N。压缩期间显示状态；对话菜单可手工修改最近摘要。最近 N 条未压缩消息可编辑并重新生成；修改非末尾消息时必须确认删除后续记录。

## 自动验收

- JavaScript 语法与运行资源引用检查。
- LLM 四类协议请求和结果解析。
- 群聊顺序、空消息点名、全部参与角色设定、逐对话 N、失败隔离、停止、重试和存储失败恢复。
- 长消息分块、媒体引用回收、TTS 停止、ASR multipart 和取消行为。
- DOM 流程：模型服务 → 角色 → 对话、草稿、安全文本、错误重试、停止、改名、搜索、设置与四标签导航。
- `chataxi-v0.3.0.zip` 与 `haminn-install.json` 的文件集合、字节和 SHA-256 一致性。

自动验收通过后仍只说明源码合同成立。部署、真实供应商凭据请求、设备安装、Android 系统语音能力和视觉效果需要单独验收。
