# chataxi 0.3.7 容器宽度修订

页面、卡片、表单、菜单、Sheet、模型列表与模型开关行统一使用可收缩宽度约束。长模型名、模型 ID、能力说明、端点和菜单文字可以断行；它们不能把父容器撑宽。

模型服务卡和服务编辑 Sheet 的模型条目显式限制在父容器宽度内，文字区可收缩并按任意位置断行。Sheet 宽度从 `100vw` 改为父视口的 `100%`，避免桌面浏览器滚动条导致的额外横向宽度。

群聊角色 Chip 与待发送图片从横向滚动改为自动换行。项目样式中禁止 `overflow-x: auto/scroll` 和 `width: 100vw`，验证脚本会持续检查该约束。没有执行浏览器截图或真机视觉验收。
