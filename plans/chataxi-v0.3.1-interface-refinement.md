# chataxi 0.3.1 界面收敛记录

日期：2026-09-14  
范围：chataxi happ 的 Sheet、对话编辑、角色头像、模型选择、设置布局和版本化归档；不含部署、手机安装和真机视觉验收。

## 交付结果

所有新增、编辑、确认与枚举选择统一为横向铺满屏幕的底部 Sheet。编辑 Sheet 可以叠加模型、服务、音色等选择 Sheet，关闭选择层后保留父表单内容。模型服务的名称、端点、协议、模型 ID 和 Header 收入默认折叠的“更多设置”，三个服务分类共用同一结构。

对话不再要求用户选择单聊或群聊：一位参与角色自动成为单聊，两位及以上自动成为群聊。最近完整消息设置直接显示为 5–50 滑杆，默认 10。列表参与者文本统一为“群聊 | Alice · Bob”或“单聊 | Alice”，并在超长时省略。

角色编辑删除快速模板、图标和颜色头像。用户可以选择本地 JPEG、PNG 或 WebP 图片，在独立 Sheet 中调整缩放与水平、垂直位置后保存方形头像。没有本地图片时，名称为空显示用户图标，有名称后显示首字符。具体模型只能从所选模型服务的列表 Sheet 选择；系统朗读不显示不存在的 TTS 模型与音色层级。

顶部标题图标、标题文字、卡片头像、正文和横排按钮统一间距；对话首页标题后显示当前版本。设置页与 Sheet 内容改用沉浸式分区，删除嵌套卡片背景和轮廓。

## 验收边界

自动检查覆盖运行脚本、资源引用、协议适配、群聊上下文、数据迁移、选择 Sheet、单群聊自动判定和关键 DOM 流程。头像裁切使用浏览器 Canvas 与本机媒体存储，仍需在 HaminnApp 真机上验证图片选择器、EXIF 方向、触控滑杆和最终显示效果。
