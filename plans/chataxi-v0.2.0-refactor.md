# chataxi 0.2.0 统一重构记录

日期：2026-09-13。状态：源码、自动检查、DOM 流程检查和本地归档完成；本轮未执行部署、设备安装、浏览器视觉验收或真实供应商调用。

本轮对象限定为 chataxi 仓库。交付是在现有单聊、有限群聊、图片、TTS/ASR 能力之上，统一首次使用、日常聊天、角色管理和设置。保留普通 happ、纯原生页面、四类显式模型协议、本机持久化及逐 happ 授权边界。

## 设计与流程

三个主入口仍为对话、角色、设置。视觉统一为温暖中性色与出租车黄，浅色、深色和跟随系统共用语义 token。手机底部导航、大屏侧栏、列表、角色卡片、设置卡片、表单和弹层采用一致的间距、边框、字号及按钮层级。

首次进入的主要动作从“连接模型”开始，保存后继续创建角色，再选角色进入对话。角色提供通用助手、写作伙伴、思考搭档三个可编辑起点。后续独立添加连接时不强制创建角色，也不自动发送收费测试。

对话列表支持标题、参与角色和最近消息搜索，支持单聊/群聊筛选、置顶、草稿摘要与配置异常提示。管理菜单集中提供编辑标题/参与者、置顶、文字导出、删除；删除不再占据聊天页的主要操作位置。

聊天页把多行输入与工具栏分开，默认 Enter 换行，Ctrl/Command + Enter 发送；通用设置可启用 Enter 发送。系统识别结果只回填文字。群聊显示本轮调用人数，支持全部角色或选择部分角色，按对话中的顺序各回复一次。

文字与附件草稿按对话保存，切页前等待持久化；用户消息保存成功后才清空编辑器。失败消息原位重试，只使用该消息之前的历史；不重新发送用户消息，不把后续轮次混入旧问题。停止会结束本轮后续编排并忽略迟到结果；Haminn 原生请求没有公开的中止合同，因此不能承诺已发出请求停止计费。

设置使用统一的连接卡片和表单，基础项与高级参数分离。密钥始终遮罩，留空保留，勾选清除才删除；更换预设地址时默认清除旧服务密钥，避免把原密钥带到其他服务。模型测试结果带时间和成功/失败说明，仅对应测试时的配置，编辑后清除旧结果。朗读和识别服务可直接设为默认；删除语音服务先修复引用。

## 实现与数据兼容

`app/features/chat-session.js` 管理有界群聊、原位重试、停止和中断恢复；`app/features/chat.js` 负责视图、输入和草稿交互。`app/services/profiles.js` 统一角色可用性、引用校验和语音默认值处理；图片压缩独立到 `app/services/images.js`。组件层统一异步错误、弹层焦点、Escape 与遮罩取消；剪贴板适配归入 platform。

保留 `chataxi.v1.*` 结构化数据前缀和既有集合，新增 `drafts` 与 `message-text` 集合。短消息格式不变；超过记录大小阈值的正文分段保存，写完新正文后再切换消息引用，读取时还原全文。现有 0.1.x 数据可直接读取，不清空或批量改写。0.1.x 旧程序不认识新草稿和分段正文，因此不能把直接降级运行视为无损回退方案。

IndexedDB 图片写入等待事务提交，不再把纯内存缓存伪装成持久化。删除对话后仅释放没有其他消息或草稿引用的图片。聊天节点按消息内容复用，异步绘制带页面与轮次校验；阅读历史时保持滚动位置，并提供回到最新入口。

网络统一校验 URL 和自定义 Header，禁止凭据 URL、传输头覆盖及换行注入。修正浏览器 ASR multipart Content-Type 的 boundary。Anthropic API Key 使用 `x-api-key`；补充结构化 image_url 和 Gemini inlineData 解析。普通链接和引用不再被当作图片自动加载。

TTS 增加停止令牌，晚到的音频不会在停止后开始播放，结束后清理 Blob/逻辑文件。ASR 取消时移除监听，核对会话标识，系统能力探测期间取消也不会随后开启麦克风。

保留并回归测试每个运行文件的字节与源文件一致性校验，补充重复归档条目检查。不同内容不能覆盖已有版本包；运行版本与 manifest 版本必须一致。发布包只归档运行文件，源码仍可直接运行，无构建步骤。
