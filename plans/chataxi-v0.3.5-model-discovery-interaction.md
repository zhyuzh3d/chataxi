# chataxi 0.3.5 模型发现与交互修订

语言模型服务编辑区将网络连接与本地保存拆开。API Key 下方提供“连接服务并获取模型”，编辑既有服务时显示“重新连接并获取模型”；连接成功后展示服务返回的全部模型，用户以统一 Switch 决定哪些模型可以被角色使用，底部始终使用“保存设置”。

模型能力采用两层信息：服务接口返回的参数元数据优先，内建家族目录补足已知模型能力。界面展示模型家族共同参数与每个模型的特别参数，角色选择具体模型后只显示该模型已确认支持的温度、推理强度、图片生成等进阶设置。多数供应商的模型列表接口不提供完整参数模式，因此未知能力保持关闭或隐藏，不能把目录推断描述成服务端事实。

角色头像选择继续由头像本身触发系统图库，裁切 Sheet 改为直接拖动图片定位，并用按钮调整缩放，不再使用横向或纵向位置滑杆。角色编辑分区只保留一条分隔线，开关统一使用 Switch，横排按钮组使用明确间距。

自动检查覆盖模型列表地址推导、授权头、服务返回的能力元数据、家族共同参数、角色可见模型过滤、保守能力回落、服务保存流程以及拖拽裁切结构。真实供应商 API、Android Photo Picker 触控体验和真机视觉仍属于后续设备验收。
