# chataxi 0.4.3 朗读服务与头像裁切修订

本次修改修复 ElevenLabs 受限密钥的错误失败判断，增加豆包语音家族，并把角色和用户头像统一为有严格覆盖约束的正方形裁切器。

ElevenLabs 的模型目录与音色目录改为独立请求。若密钥能读取账户音色但缺少 `models_read`，连接流程改用内置的稳定模型目录，并继续执行最短文本的真实合成测试；模型和音色都不可读时仍视为失败。供应商返回的 `detail.message` 会显示为可读错误，不再统一显示无错误说明。连接成功状态会说明采用内置目录的原因。

豆包语音采用新版控制台的单 API Key 鉴权，发送 `X-Api-Key`、所选模型对应的 `X-Api-Resource-Id` 和每次唯一请求 ID。适配器调用 V3 HTTP SSE 接口并合并 Base64 音频片段。内置语音合成 2.0、1.0与声音复刻 2.0、1.0资源；预置常用音色，账户的其他音色 ID 可在更多设置补充。角色选择具体资源和音色，并只在模型支持时显示语速、音调、音量滑杆。

头像裁切器以蓝色正方形和九宫格表示最终 320×320 输出区域。图片按短边覆盖方框初始化，缩放下限固定为覆盖状态，位移在每次拖动、捏合、滚轮或按钮缩放后重新约束。导出计算再次钳制源矩形，因此横图、竖图和极端拖动都不能产生框外空白。角色与“我的”页面继续共用同一裁切器，已有移除头像入口保留。

自动检查覆盖 ElevenLabs 模型权限缺失时的回退、分页账户音色、豆包鉴权头与请求体、SSE 多段音频合并、供应商错误、横竖图裁切覆盖和源区域边界。真实 ElevenLabs 密钥已在不写入项目的前提下验证模型目录 401、音色目录 200和最短文本合成 200；豆包没有提供测试密钥，因此只完成协议级测试，未声明真实供应商验收。
