# chataxi 0.3.3 角色媒体与能力修订

角色编辑 Sheet 移除独立的“选择本地图片”按钮。角色头像本身作为图片入口，右下角相机标记只用于提示可编辑；点击后调用 Hermit `files.pickImage`，由宿主打开 Android Photo Picker，再进入原有方形裁切 Sheet。

朗读设置增加试听按钮，使用表单中当前选择的朗读服务、TTS 模型、音色和受支持的音色提示词播放“你好！欢迎使用朗读功能。”。服务停用、必要模型缺失，或 ElevenLabs 尚未取得音色时，试听按钮直接禁用。

能力相关字段按具体模型和服务收敛：不支持温度时隐藏温度，不支持推理强度时隐藏推理滑杆，不支持图片生成时隐藏开关；系统朗读、单一模型、单一音色和不支持音色提示词的组合不显示无效下级字段。模型列表为空时具体模型选择禁用。

验收包括 chataxi DOM 流程、全部逻辑测试、HermitApp 受影响 Kotlin 编译和版本化 ZIP 校验。部署与真机交互验收仍是独立门槛。
